Backup & Disk Mirroring

Backup creates copies of data to restore after loss. Disk mirroring (RAID 1) writes identical data to two disks simultaneously, so if one fails, the other continues working.

Learning Objectives

  • 12.1.2.2 Use data protection measures such as data backup and disk mirroring

Conceptual Anchor

The Photocopier Analogy

Backup = making a photocopy of an important document and storing it in a safe. If the original is lost, you use the copy. Disk mirroring = having two pens write simultaneously — if one runs out of ink, the other keeps writing without interruption.

Rules & Theory

Backup Types

Type What It Backs Up Speed Storage
Full backup ALL files every time Slowest to create Uses most space
Incremental Only files changed since LAST backup (any type) Fastest to create Uses least space
Differential All files changed since last FULL backup Medium speed Medium space
BACKUP SCHEDULE EXAMPLE (1 week): Mon: FULL backup (all 100 GB) Tue: Incremental (only 2 GB changed since Mon) Wed: Incremental (only 1 GB changed since Tue) Thu: Incremental (only 3 GB changed since Wed) Fri: FULL backup (all 100 GB again) RESTORE from Thursday: Need: Mon Full + Tue Inc + Wed Inc + Thu Inc = 4 files WITH DIFFERENTIAL: Mon: FULL backup (100 GB) Tue: Differential (2 GB changed since Mon) Wed: Differential (3 GB changed since Mon) ← cumulative! Thu: Differential (6 GB changed since Mon) RESTORE from Thursday: Need: Mon Full + Thu Diff = only 2 files (simpler!)

Backup Locations

Location Advantages Disadvantages
External HDD/SSD Fast, portable, no internet needed Can be lost/stolen/damaged
Cloud storage Off-site, accessible anywhere, automatic Needs internet, monthly cost, privacy concerns
Network (NAS) Shared, centralised, automatic Vulnerable to same disaster as main system
Tape drive Very large capacity, cheap per GB Slow access, sequential read

Disk Mirroring (RAID 1)

Feature Details
How it works Data is written to two (or more) disks simultaneously
If one disk fails The other disk continues without downtime
Advantage High availability — no data loss from single disk failure
Disadvantage Doubles storage cost (need 2× disks for same capacity)
NOT a backup If you delete a file, it's deleted on BOTH disks. Mirroring ≠ backup!

The 3-2-1 Rule

Best practice: keep 3 copies of data, on 2 different media types, with 1 stored off-site (e.g., cloud). This protects against hardware failure AND physical disasters.

Common Pitfalls

"RAID IS a Backup"

RAID (disk mirroring) protects against hardware failure only. It does NOT protect against accidental deletion, ransomware, or corruption — those affect both mirrored disks. You still need separate backups.

Tasks

Self-Check Quiz

Q1: What is the difference between incremental and differential backups?

Incremental backs up changes since the LAST backup (any type). Differential backs up all changes since the last FULL backup.

Q2: What is disk mirroring?

Writing identical data to two disks simultaneously (RAID 1). If one disk fails, the other continues working.

Q3: What is the 3-2-1 backup rule?

Keep 3 copies of data, on 2 different media types, with 1 copy stored off-site.
