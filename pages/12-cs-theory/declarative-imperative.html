Declarative vs Imperative Programming

Programming languages can be classified by how they solve problems. Imperative languages tell the computer how to do something step by step. Declarative languages describe what the result should be.

Learning Objectives

  • 12.5.1.1 Compare declarative and imperative programming languages
  • 12.5.1.2 Create a simple expert system
  • 12.5.1.3 Describe program compilation stages: lexical and syntactic analysis, code generation, and optimization

Conceptual Anchor

The Restaurant Analogy

Imperative = giving the chef step-by-step cooking instructions: "Boil water, add pasta, cook 10 min, drain, add sauce." Declarative = just ordering from the menu: "I want pasta bolognese." You describe WHAT you want, not HOW to make it.

Rules & Theory

Imperative vs Declarative

Feature Imperative Declarative
Approach Describes HOW to solve Describes WHAT to achieve
Control flow Explicit (loops, if/else) Implicit (engine decides)
State changes Variables change over time No mutable state
Examples Python, Java, C, Pascal SQL, Prolog, HTML, CSS
Advantages Fine control, familiar, efficient Shorter code, fewer bugs, easier to read
Disadvantages More code, harder to reason about Less control, harder to debug

Code Comparison

# IMPERATIVE (Python) — HOW to find even numbers numbers = [1, 2, 3, 4, 5, 6, 7, 8] evens = [] for n in numbers: if n % 2 == 0: evens.append(n) print(evens) # [2, 4, 6, 8]
-- DECLARATIVE (SQL) — WHAT you want SELECT * FROM numbers WHERE value % 2 = 0;

Expert Systems

Component Purpose
Knowledge Base A collection of facts and rules about a specific domain
Inference Engine Applies rules to known facts to derive new conclusions
User Interface Allows users to input queries and receive answers
% Simple Expert System in Prolog (declarative) % Knowledge Base — Facts: animal(dog). animal(cat). has_fur(dog). has_fur(cat). says(dog, woof). says(cat, meow). % Rules: pet(X) :- animal(X), has_fur(X). % Query: ?- pet(dog). % Result: true ?- says(cat, Y). % Result: Y = meow

Compilation Stages

Stage What It Does Example
1. Lexical Analysis Breaks source code into tokens (keywords, identifiers, operators) x = 5 + 3 → tokens: [x] [=] [5] [+] [3]
2. Syntax Analysis Checks tokens follow grammar rules; builds a parse tree Detects x = 5 + as invalid (missing operand)
3. Code Generation Converts parse tree to machine code (binary instructions) ADD R1, R2 → 00101001...
4. Optimization Improves code efficiency without changing results Removes dead code, simplifies expressions

Prolog — The Declarative Language

Prolog is a logic programming language used for expert systems and AI. You define facts and rules; the inference engine finds answers. You never write loops or if-statements — you just ask questions!

Common Pitfalls

SQL is NOT Imperative

SQL says what data you want, not how to find it. SELECT * FROM students WHERE age > 16 doesn't specify searching algorithms — the database engine decides.

Tasks

Remember

List 3 imperative and 3 declarative languages.

Understand

Explain each compilation stage and what happens at each step.

Apply

Write a simple expert system (facts + rules) in Prolog for diagnosing 3 common illnesses based on symptoms.

Self-Check Quiz

Q1: What is the main difference between imperative and declarative?

Imperative describes HOW to solve a problem (step-by-step). Declarative describes WHAT the result should be.

Q2: What are the 3 components of an expert system?

Knowledge Base (facts + rules), Inference Engine (applies rules), User Interface (input/output).

Q3: What does lexical analysis produce?

Tokens — the source code is broken into meaningful units like keywords, identifiers, operators, and literals.
