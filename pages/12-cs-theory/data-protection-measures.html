Data Protection Measures

Protecting data and systems requires multiple layers of defense. Firewalls block unauthorized network access, encryption scrambles data, and biometrics verify identity using unique physical traits.

Learning Objectives

  • 12.1.2.1 Describe protection measures for data and computer systems such as firewalls, encryption, biometrics

Conceptual Anchor

The Bank Vault Analogy

A bank uses security guards (firewall — controls who enters), a vault with coded lock (encryption — data unreadable without the key), and fingerprint scanner (biometrics — proves identity). Multiple layers make it much harder to break in.

Rules & Theory

Firewalls

Feature Details
What it does Monitors and filters incoming/outgoing network traffic based on rules
Types Software firewall (Windows Defender), Hardware firewall (router-based)
How it works Packet filtering — checks source/destination IP, port numbers, protocols
Limitation Cannot detect threats inside encrypted traffic; cannot stop insider threats

Encryption

Feature Details
What it does Converts plaintext into unreadable ciphertext using an algorithm and key
Symmetric Same key for encryption and decryption (AES). Fast, but key must be shared securely
Asymmetric Different keys: public key (encrypt) + private key (decrypt) (RSA). Slower but more secure
Use cases HTTPS websites, email (PGP), disk encryption, messaging (WhatsApp E2E)
ENCRYPTION EXAMPLE: Plaintext: HELLO WORLD Key: Shift by 3 (Caesar Cipher) Ciphertext: KHOOR ZRUOG Without the key, "KHOOR ZRUOG" is meaningless. With the key (shift back by 3), you recover "HELLO WORLD".

Biometrics

Biometric How It Works Pros Cons
Fingerprint Scans unique ridge patterns Fast, widely available Can be fooled by copies; dirty fingers fail
Facial recognition Maps facial geometry (distance between eyes, nose shape) Contactless, convenient Affected by lighting, aging, twins
Iris scan Photographs unique patterns in the iris Extremely accurate Expensive equipment
Voice recognition Analyzes voice patterns and tone Hands-free Affected by illness, background noise
Retina scan Maps blood vessels at the back of the eye Nearly impossible to forge Intrusive, very expensive

Defense in Depth

No single measure is enough. Best practice is layered security: firewall + antivirus + encryption + strong passwords + biometrics + regular updates.

Common Pitfalls

"A Firewall Stops All Attacks"

Firewalls only filter network traffic. They don't protect against social engineering, USB-based malware, or insider threats. Always combine with other measures.

Self-Check Quiz

Q1: What does a firewall do?

Monitors and filters incoming/outgoing network traffic based on predefined security rules.

Q2: What is the difference between symmetric and asymmetric encryption?

Symmetric uses the same key for encryption and decryption. Asymmetric uses a public key to encrypt and a private key to decrypt.

Q3: Name one advantage and one disadvantage of fingerprint recognition.

Advantage: fast and widely available. Disadvantage: can be fooled by copies; dirty/wet fingers may fail.
